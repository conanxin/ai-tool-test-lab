AI Tool Test Lab

一个记录 AI 工具真实测试过程的开源实验室

AI Tool Test Lab 是一个记录 AI 工具、平台、开源项目真实测试过程的开源实验室。每个测试项目最终只用一个页面展示完整测试过程——从本地环境评估到云端训练，从成本核算到最终结论，全部透明公开。

Case workflow standard

本实验室的所有测试案例都遵循统一的工作流标准。第一个 canonical example 是 Castform Hermes Phase Closer v0。

  • Castform Hermes Phase Closer v0 is the first canonical case. 未来所有 AI 工具 / 平台 / 开源项目的测试，都将使用同样的流程与文档结构。
  • Future AI tools will be tested with the same flow. Discovery → Local readiness → Scaffold → Local validation → Guarded external run → Monitoring → Failure analysis → Closeout。
  • Each case gets one page. 一个案例对应一个独立的 case 页面，只展示结论，不堆全部原始日志。
  • Each stage gets reports. 每个阶段都有报告，命名遵循 ATL-N_*_REPORT.md 格式。
  • Each run records what worked, what failed, and what remains unknown. 每次执行都清晰记录成功证据、失败证据、未知项。
  • Every case ends with closeout. 每个案例最终必须有 CASE_CLOSEOUT.md + 最终阶段报告 + data/cases.json 中的最终状态字段。

详细规范见 docs/CASE_WORKFLOW_STANDARD.md、docs/CASE_PHASES.md、docs/CASE_TEMPLATE.md。
