项目概览

Castform 是一个模型微调平台，支持 RL（强化学习）后训练。本项目测试将其用于训练一个 "Hermes Phase Closer" 模型：输入 agent 阶段报告，输出结构化的阶段总结，包含结论、状态、设计理由、修改影响、验证结果、风险边界和下一步。

为什么测试 Castform

  • 现有 Hermes Agent 在 phase 收尾时依赖模板填充，缺乏对上下文的深度理解。
  • 希望训练一个专用小模型，专门负责从阶段报告中提取关键信息并生成结构化输出。
  • Castform 提供 RL 训练环境，可能比传统 SFT 更适合这种结构化生成任务。
  • 需要评估：成本、数据需求、训练稳定性、输出质量。

测试目标：Hermes Phase Closer v0

训练一个模型，使其能够：

  • 输入：一份 agent 阶段报告（Markdown 格式，含任务列表、验证结果、问题记录）。
  • 输出：JSON 结构化的阶段总结，包含 7 个字段：阶段结论、当前状态、设计理由、修改影响、验证结果、风险边界、下一步。
  • 约束：输出中不得出现任何 token、api_key、secret、密码等敏感信息。

本地电脑能做什么

  • 整理和清洗训练数据（JSONL 格式）。
  • 编写 reward 评分标准（rubric）。
  • 本地 dry-run 验证数据格式和样本质量。
  • 编写和测试调用 Castform API 的 Python 脚本（stub 阶段）。
  • 维护测试记录页面和文档。

什么必须交给 Castform 云端

  • GPU 训练（RL fine-tuning）。
  • 模型评估和 playground 测试。
  • 大规模推理和 batch 生成。

数据准备方案

使用合成脱敏样本。每个样本包含：

  • prompt：虚构的 agent 阶段报告。
  • ground_truth：期望的结构化 JSON 输出。

样本覆盖场景：成功阶段、失败阶段、部分完成阶段、需要回滚阶段。

样本格式

参见 sample-train.jsonl 和 sample-eval.jsonl。

{
  "prompt": "## Phase 2-a 完成报告\n\n任务：实现用户登录模块\n验证：pytest 通过 12/12\n问题：无\n下一步：Phase 2-b 权限管理",
  "ground_truth": "{\"conclusion\":\"用户登录模块已完成\",\"status\":\"PASS\",\"design_reason\":\"采用JWT token减少session查询\",\"impact\":\"新增依赖pyjwt，修改了auth中间件\",\"validation\":\"pytest 12/12通过\",\"risk\":\"token过期时间需线上调优\",\"next_step\":\"Phase 2-b 权限管理\"}"
}

reward 评分标准

参见 reward-rubric.md。

  • 阶段结论正确（1 分）
  • 当前状态清楚（1 分）
  • 设计理由明确（1 分）
  • 修改影响完整（1 分）
  • 验证结果具体（1 分）
  • 风险边界清楚（1 分）
  • 下一步可执行（1 分）
  • 出现 token / api_key / secret 直接 0 分（安全红线）

本地验证计划

  • 验证 JSONL 格式正确性（每行合法 JSON，必需字段存在）。
  • 验证 prompt 和 ground_truth 不为空。
  • 验证 ground_truth JSON 包含全部 7 个字段。
  • 扫描敏感信息泄露（token、key、secret、password）。
  • 运行 reward rubric 的本地 dry-run（不调用模型，仅检查评分逻辑）。

云端训练计划

  • Phase 4：上传 30 条样本，启动小规模 smoke run（1–2 个 epoch）。
  • 观察训练曲线、reward 变化、输出稳定性。
  • Phase 5：在 playground 用 10 条 hold-out 样本评估。
  • 对比基线模型（如 GPT-4o-mini）和训练后模型的输出质量。

成本与限制

  • Castform 训练按 token 和 GPU 时间计费，具体价格需查阅官方文档。
  • 本地 GTX 1070 8GB 无法运行训练，只能做数据准备。
  • 预计首次 smoke run 成本：$5–$20（取决于模型大小和训练步数）。
  • 限制：需要有效的 CASTFORM_API_KEY 和足够的 account credit。
