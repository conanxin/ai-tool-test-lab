EvoMap 是 AI agent 自进化/经验复用基础设施；Evolver 是本地 CLI 工具，用来读取 agent / 项目运行历史、失败日志、上下文，然后生成可复用的修复/改进 prompt。官方说明 Evolver 需要 Node.js >= 18 和 Git，并且需要在 git repo 中运行。测试重点不是“相信公共 EvoMap Hub”，而是验证本地 Evolver 能否帮助 OpenClaw 总结失败日志、生成下一步修复策略。

硬边界：
1. 不连接 EvoMap Hub。
2. 不设置 A2A_HUB_URL。
3. 不开启 evolver --loop。
4. 不开启 validator。
5. 不自动发布 Gene / Capsule。
6. 不消耗 credits。
7. 不写入任何 API key / token / cookie / Authorization header。
8. 不修改我现有 OpenClaw / Hermes / systemd / cron 配置。
9. 不运行任何后台 daemon。
10. 不把 node_modules / .env / 私密日志提交到 repo。
11. 只在 ai-tool-test-lab 仓库内新增文档、测试夹具、验证脚本和报告。
12. 如需安装 npm 包，只允许安装 @evomap/evolver；不要安装无关依赖。
