# 案例模板

新增测试案例时，按以下结构填写。

## 必填信息

- **项目名称**：工具/平台/开源项目的名称
- **项目链接**：官方网站或 GitHub 仓库
- **测试目的**：为什么测试这个工具？解决什么问题？
- **本地环境**：操作系统、硬件、已有依赖
- **安装过程**：安装步骤、遇到的问题、解决方案
- **核心功能测试**：测试了哪些功能？输入什么？输出什么？
- **成本与限制**：价格、免费额度、硬件要求、使用限制
- **问题记录**：遇到的 bug、错误、不一致行为
- **最终结论**：是否达到预期？是否值得继续使用？
- **是否值得继续**：YES / NO / MAYBE（需满足什么条件）

## 可选信息

- **对比测试**：与同类工具的横向对比
- **长期观察**：使用一段时间后的稳定性评估
- **社区活跃度**：GitHub stars、issue 响应速度、更新频率
